# watch-bot: задачи (префикс WB)

Канбан-доска открытой работы. Правила ведения в devkit, RULES.md раздел
«Трекинг задач». Строка держит метаданные и короткий заголовок, разбор
задачи живёт в файле tasks/WB-NNN.md. Механику доски гоняет taskctl,
таблицы руками не править. Закрытое переезжает в
[TASKS-archive.md](TASKS-archive.md).

Приоритет P выводится из ранга R по RANKING.md (devkit). Формула
R = Серьёзность(0-75) + Ценность(0-10) + Неопределённость(0-5) + Баг(+5) + Рычаг(0-5),
колонка R держит сумму и разбивку в этом порядке. Бакеты: P0 при R >= 75, P1
при 50-74, P2 при 25-49, P3 при 0-24. Типы: bug / task / LLD. Цена это грубая
оценка затрат агента на исполнение (S / M / L / XL, шкала в RANKING.md), в
ранг она не входит, прочерк значит «не оценено». Backlog отсортирован по R
убыванию, при равенстве по возрастанию ID.
