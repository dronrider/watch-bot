# WB-001: Адаптер codexreset.org: последний сброс и прогнозы по якорям разметки

## Что происходит

Четвёртый известный источник Codex-сбросов, codexreset.org, не подключён.
Сайт отдаёт одностраничник на мегабайт без API и без фида, под хелперы хоста
он не лёг вместе с остальными. Прогнозы сброса при этом есть только у него.
Панели оценок на 24 и 48 часов несут пометку experimental.

Разведка 2026-10-25 нашла в разметке устойчивые якоря. Точное время
последнего сброса стоит в теге time с атрибутом dateTime, сегодня это 06:06
UTC, тот же пост, что у подключённых источников. Панели прогноза несут
data-testid. История на 828 дат зашита в сериализованное состояние
фреймворка и регулярному разбору не поддаётся.

## Чего хотим

Адаптер adapters/codexresetorg.js читает главную страницу и собирает два
события. Первое это смена времени последнего сброса (вид reset), второе
смена категории прогноза (вид forecast). Разбор идёт регекспами по якорям,
DOM-парсера в песочнице goja нет. Прошлые значения держатся в kv источника,
новым событие становится при смене значения якоря. Историю фреймворкового
состояния не разбираем. Сбросы уже покрывает codexreset.dev, ценность
источника в прогнозах. Событием считается смена категории прогноза,
колебания процента внутри категории молчат.

## DoD

- адаптер собирает события с главной, формат сверен золотым снимком боевой
  выдачи
- источник включён в конфиг с service = "Codex", своим расписанием и порогом
  свежести
- совпавший с другим источником пост X склеивается сквозным дедупом
- выкат на машину алертов и живое уведомление от нового источника

## Ранг

`0+6+2+0+3 = 11`, P3.

- Серьёзность 0: источник дублёр, работа не стоит.
- Ценность 6: прогнозы это сигнал, которого нет у трёх подключённых.
- Неопределённость 2: якоря разведаны, вёрстка может смениться.
- Поправка на баг 0: сбросы уже покрывают подключённые источники, бага нет.
- Рычаг 3: третий адаптер на готовой песочнице без правок хоста.
